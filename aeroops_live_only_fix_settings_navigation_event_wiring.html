iPhone Browser & Bookmark Guide

Host on an https:// URL for Safari & Chrome

📲

On iPhone, opening a local .html file from the Files app opens a limited Quick Look preview instead of Safari or Chrome, and cannot be bookmarked cleanly like a website. Host this single HTML file on a free static https:// host first:

  1. Netlify Drop: Go to app.netlify.com/drop on a computer or browser, drop aeroops-live-only.html (or a folder containing it as index.html), and copy the generated https:// URL.
  2. GitHub Pages: Create a free repository, upload index.html (this file), and enable Settings → Pages to get a permanent https:// link.
  3. Bookmark or Add to Home Screen on iPhone: Open the https:// link in Safari (or Chrome), tap Share → Add to Home Screen (or tap the Bookmark icon).
